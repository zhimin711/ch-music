# Android 蓝白界面改版

本轮仅修改 Android 客户端，保留 MusicServer API、播放服务和用户已选择的播放器皮肤。

## 已实现

- 默认蓝白主题和深色配色；保留显式设置的 Material You、纯黑主题及自定义强调色。
- 首页头像与胶囊搜索框、独立分类栏、推荐标题区、圆角封面与统一歌曲行；推荐模块可单独重试。
- 恢复首页 / 笔记 / 我的导航；展开播放器时隐藏导航，收起后恢复。搜索、详情、账号等次级页面隐藏主导航。
- 迷你播放器显示歌曲与歌手、线性进度、播放与队列入口；保留可选的上一首 / 下一首。
- 搜索结果增加更多操作入口；推荐与搜索歌曲突出当前播放曲目。
- 歌单详情采用封面取色背景，可展开标题和简介，支持原有播放及随机播放操作。
- 默认 Adaptive 播放器采用低饱和封面渐变，歌曲信息移至封面下方，加入封面 / 歌词切换；横屏控制区可滚动。
- 我的页面聚合账号、收藏、歌单、音乐库、缓存管理和设置；缓存入口进入现有音乐库管理页面。数量读取账号数据，获取失败时支持重试。
- 笔记保留空状态，不增加笔记业务。

## 验证记录

- XML 全量解析、修改文件的 Kotlin 语法解析和差异空白检查通过。这些静态检查不等同于 Android 编译或运行验证。
- 尝试 `./gradlew assembleNormalDebug assembleFdroidDebug lint`：项目指定的 Gradle 8.14.5 下载超时。
- 使用本机缓存的 Gradle 8.14.2 和 JDK 21 尝试离线执行同一组任务：明确报错 `SDK location not found`，尚未进入 Android 编译和 lint。
- 当前环境没有可用的 Android SDK / 模拟器，未生成 APK 或实机截图。

## 待在 Android 环境完成的验收

1. 配置 Android SDK 35、项目所需构建工具和 JDK 21，执行上述两个 flavor 的构建及 lint。
2. 分别在浅色、深色、纯黑及已保存的 Material You 设置下打开首页、我的、歌单详情和播放器；检查文字对比度与背景一致性。
3. 在 360dp 窄屏、横屏、最大系统字体、手势导航与三键导航下检查底部间距和末行可见性。无歌曲时仅显示导航；有歌曲时迷你播放器位于其上方。
4. 从首页搜索并播放，打开歌单、展开播放器、切换歌词、拖动进度、打开队列及返回；核对歌曲、进度、播放状态和导航选中项。切换主页面不应重置播放。

7. 切换到其他已保存的播放器皮肤，确认其布局和操作仍可使用。
8. 保存首页、搜索、歌单详情、播放器及我的页面的浅色 / 深色截图作为视觉验收记录。
